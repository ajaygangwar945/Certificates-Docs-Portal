## 📖 Project Overview

A premium, high-performance portfolio portal for showcasing professional certifications, awards, and educational achievements. This project transforms a flat directory of PDF documents into an interactive, searchable, and beautifully themed web experience.

---

## 🌟 Key Features

### 🔍 Intelligent Search & Filtering

- **Real-time Search**: Instantly find certificates by title, technology, or description.
- **Category Chips**: Filter documents by tags like **AWS**, **Google**, **Hackathons**, **Web Dev**, and more.
- **Statistics Dashboard**: Live counters for total assets and categories.

### 🎨 Granular Visual Identity

The portal now features an advanced **Granular Brand Mapping** engine. It goes beyond simple category tags to apply specific, context-aware icons:

- **Python Data Science** gets a Python logo, while **General Data Science** gets a Chart icon.
- **Packet Switching** gets a Box icon, while **General Networking** gets a Network structure icon.
- **Web Development** distinguishes between **Full Stack** (Layer Group), **Frontend** (Window), and **Backend** (Server).

### 🌗 Premium UI/UX

- **Dual Theme Support**: Beautifully optimized Light and Dark modes.
- **Subtle Interactivity**: High-end border highlight effects and glassmorphism.
- **Responsive Design**: Flawless experience across desktop, tablet, and mobile.

---

## 🛠️ Technical Stack

- **Core**: Semantic HTML5 & Modern CSS3
- **Logic**: Vanilla JavaScript with Advanced Regex Matching
- **Icons**: FontAwesome 6.4 & Custom Branded SVGs
- **Typography**: Google Fonts (Outfit)
- **Design**: Modern Glassmorphism & Hardware-Accelerated Rendering

## 📂 Project Structure

The project consists of a high-end interface managing **80+** professional documents:

- `index.html`: The main portal (Single-file architecture).
- `README.md`: Project documentation.
- `...pdfs`: Professional certificates and achievements.

### Featured Tracks

| Track | Highlights |
